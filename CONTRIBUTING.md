# Contribution guidelines

Feel free to join us by making contributions if you have something related to this list!

Following edits are **suggested**:

1. Add/update papers and tools and related information;
2. Fix existing mistakes (e.g. misplaced papers, 404 hyperlinks, mis-ranked papers by time);
3. Add sub-headings and start a new sublist;

Following edits are **supportive**, but they should be **carefully considered**:

1. Delete over-dated papers without much reference value (e.g. those without source codes or solid data);
2. Delete or combine sub-headings with papers kept;

Following edits are **not allowed**:

1. Add large media files (e.g. large images or videos) into [README.md](README.md) — too many large files reduce loading speed;
2. Add content with copyright protection that restricts re-link or reprint without authorization from copyright owners;

## Format of paper / tool items

1. Language is not restricted; English is preferred if possible.
2. Citation formats are not restricted (MLA, APA, GB/T, Chicago, etc.).
3. Save edits in UTF-8.

Paper/tool items are written in **Markdown** and ranked by release date in ascending order:

> **Title of paper or tool** (bold)  
> Author names...  
> [Publishing platform (including time)] • [code] • [website] • [supplementary] • ...

Get guides at [MarkdownGuide](https://www.markdownguide.org/getting-started/) if you are not familiar with **Markdown**.

## How-to

1. Log in to your [GitHub](https://github.com/) account;
2. Open the [README.md](README.md) file in this repository;
3. Click **Edit this file**;
4. Edit README.md in Markdown following the [format](#format-of-paper--tool-items) and [guidelines](#contribution-guidelines) above;
5. Add a short description of your edit and click **Propose file change**;
6. Submit your pull request.

## Become a contributor

Once your pull request is approved, your GitHub ID will be listed among contributors.
